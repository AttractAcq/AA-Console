# V4 scene speech cost receipts

Migration 671 records one estimated Eleven v3 charge for each successful TTS response against the exact video scene, IR version, job and one-shot attempt. The service-only RPC validates the current source, narration hash, UTF-8 character count and published list-price calculation. Its attempt key is unique, so an exact replay cannot add cost twice. A stale or cross-scene job, wrong units, stale source or unstarted attempt is rejected. The audio worker files a receipt immediately after each successful TTS response and stops before alignment or Storage when the ledger write fails. An uncertain provider failure still requires account-side reconciliation; the attempt is never automatically retried.
