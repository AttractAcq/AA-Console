# SF40 — Write and attach post copy

**Where.** Clients → [client] → Delivery → Content Production Factory → **Copy**
**Owner.** Copywriter or SMM. **Reviewed.** 25 October 2026. **Part of** MF03, MF07, MF09.

## Do it
The copywriter agent writes post copy against the asset and the brief. Read it and edit it.

Copy is a **separate record from the asset**, which means:
- The same asset can carry different copy per surface
- Changing copy does not require rebuilding the asset
- Copy has its own approval path within the post's gate

## What to check
- It reads in the client's voice (from **Account → Brand & Design** and the business context)
- Every claim it makes has proof behind it — copy is where unevidenced claims sneak in after
  the offer sign-off gate (SF20)
- The call to action matches the campaign's destination. Copy saying "link in bio" on a
  campaign whose destination is a DM is a dead end

## Gotcha
`post_copy_effective` resolves which copy actually applies to a post. If a post publishes with
copy you did not expect, that is where to look.
