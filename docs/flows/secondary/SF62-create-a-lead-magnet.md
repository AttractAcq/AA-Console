# SF62 — Create a lead magnet and a version

**Where.** Clients → [client] → Delivery → Lead Magnet Studio → Magnets / Build
**Owner.** Client manager. **Reviewed.** 25 October 2026. **Part of** MF11.

## Why
Template **P5** requires *a magnet and the page that gates it*. A magnet buys contact details
with value rather than with an offer, which is why it converts a colder audience than a sales
page.

## Do it
1. **Magnets** → **Build a magnet** / **Create**. It confirms
   *"Created. Add the file as its first version."*
2. **Build** → **Add a version** — upload the actual file.

**Versions are immutable.** Replacing the content means a new version, which is what makes
MF15's drift sweep able to find a magnet still carrying an old offer.

## What makes a magnet work for a service business
Something that is useful on its own and that only this client could credibly produce — a real
cost breakdown, a checklist from their actual process, a worked example with numbers. A
generic PDF converts, then poisons the nurture that follows it.

Bind it to the offer version it quotes, so drift is detectable (SF22).
