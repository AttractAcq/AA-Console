# SF35 — Build a frame plan and regenerate one frame

**Where.** Clients → [client] → Delivery → Content Production Factory → Briefs / Create
**Owner.** Creative lead. **Reviewed.** 25 October 2026. **Part of** MF07.

## Why it exists
A reel's brief holds a frame plan — the beats, as structure rather than prose. Because it is
structured, frame three can be rebuilt while one, two and four stay exactly as approved.

## Do it
1. Read the frame plan on the brief.
2. Identify the frame that is wrong, and why — against the brief, not against taste.
3. Regenerate that frame.
4. The plan is kept; only that frame changes.

## Why not just rebuild the whole thing
Because the other frames were right, and rebuilding them produces different output that then
needs re-reviewing. The frame plan exists so a small problem costs a small fix.

## Gotcha
If two or three frames are wrong, the brief is wrong. Regenerating each frame individually
against a bad plan is slower than fixing the plan and rebuilding.
