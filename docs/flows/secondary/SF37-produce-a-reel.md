# SF37 — Produce a reel: stills, then motion

**Where.** Clients → [client] → Delivery → Content Production Factory → Create /
**Reel Shots**
**Owner.** Creative lead. **Reviewed.** 25 October 2026. **Part of** MF07.

## The one rule
**Stills before motion.** The opening stills are built and reviewed first, because a motion
render over a wrong still wastes the expensive step.

## Do it
1. Brief it with **Format** = `reel`, with a frame plan (SF34, SF35).
2. Build the opening stills. Review them in **Reel Shots**.
3. Only when the stills are right, let it go to motion. Creative stages are
   `concept` → `render` → `motion` → `done`, or `failed`.
4. **Track reel** follows the build through its stages.
5. It lands in **Videos** (**Finished reels**).

## Review gates on a reel
A reel gets more scrutiny than an image because it costs more and carries more:
1. Stills review (here)
2. QA score (SF41)
3. **Media → Video quality reviews** — the acceptance screen for continuity, visual defects,
   caption readability, crop, narrative, brand fit and brief execution
4. A person's approval (SF42)

## Gotcha
A visible action the brief required must actually be **performed**, not implied by a caption.
The acceptance screen checks this specifically, and it is the most common reason a
good-looking reel is rejected.
