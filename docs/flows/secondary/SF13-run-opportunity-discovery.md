# SF13 — Run opportunity discovery

**Where.** Clients → [client] → Delivery → Market Opportunities → Discover
**Owner.** Marketing Director. **Reviewed.** 25 October 2026. **Part of** MF02.

## Do it
**Find opportunities** queues the opportunity discovery agent. It reads the intelligence from
MF01 and proposes micro-niches, each arriving at status `discovered`.

You can also add one by hand when the client or a salesperson already knows it — that is
often the best one, because it comes from a real conversation.

## What a micro-niche is
Narrower than a service line. "Garage conversions" is one; "building work" is not.

**The test:** can you write one ad that speaks to it and would feel wrong shown to the rest
of the market? If not, it is too broad, and the content will be generic.

## Gotcha
Discovery output is only as good as the intelligence. If what comes back is vague, the fix is
in Intelligence OS (SF07, SF08), not in running discovery again.
