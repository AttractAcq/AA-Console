# SF19 — Create an offer and a version

**Where.** Clients → [client] → Delivery → Offer Studio → Service Offers
**Owner.** Client manager. **Reviewed.** 25 October 2026. **Part of** MF01, MF03, MF15.

## Do it
1. Create the **offer** — the thing the client sells.
2. Create a **version** of it, carrying the price, inclusions, guarantee and claims.

## Versions are immutable
You never edit a signed-off version; you create a new one that supersedes it. Everything
downstream — campaigns, packages, pages, magnets — freezes a specific version, which is what
makes the drift sweep in MF15 possible at all.

## Claims
Record each claim with its kind. A **quantified** claim ("saves 30%", "cheapest in
Portsmouth") must carry a proof asset, or sign-off refuses it (SF20). Capture the proof first
(SF23) if you do not have it.

## Gotcha
Create the version **before** building anything that quotes it. A campaign or page built
against no version, or an unsigned one, carries unapproved copy — and you will discover it
when sign-off or publication is refused.
