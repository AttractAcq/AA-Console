# SF27 — Request a proof artifact

**Where.** Clients → [client] → Delivery → Proof Production Factory → Proof Artifacts
(or **(v2) → Produce**)
**Owner.** Client manager. **Reviewed.** 25 October 2026. **Part of** MF06.

## Why
Raw proof is not placeable. An artifact is proof rendered for a surface.

| `artifact_kind` | For | Use when |
|---|---|---|
| `geo_answer` | The answer-shaped content a generative search engine will quote | The buyer asks an AI before they ask a person |
| `seo_case_study` | A case study page that ranks | The niche searches for outcomes |
| `local_proof_snippet` | Short local proof for a profile or a directory | Omnipresence on profiles and listings |

## Do it
1. Choose the source proof asset. It must be cleared (SF25) or the artifact cannot be signed
   off.
2. Request the artifact. The proof artifact agent builds a version.
3. Read it against the source. The artifact must not overstate what the proof says — this is
   the most common problem.
4. Sign off the version (SF28).

## Gotcha
Artifacts are versioned. Rebuilding produces a new version rather than replacing one, so a
placed artifact keeps pointing at the version that was approved.
