# SF15 — Raise confidence with evidence

**Where.** Clients → [client] → Delivery → Market Opportunities → Evaluate
**Owner.** Marketing Director. **Reviewed.** 25 October 2026. **Part of** MF02, MF13.

## The one rule
**Confidence is evidence, not enthusiasm.** It moves when something real happened, and it can
move down.

## The ladder
| Confidence | What has to be true |
|---|---|
| `hypothesis` | Somebody's idea. Nothing checked |
| `desk_research` | Market data supports it |
| `conversation` | A real prospect or the client said so out loud |
| `first_party` | Our own data for **this client** shows it |
| `proven` | It has produced cash |

## When to move it
- After a client call that confirmed the niche → `conversation`
- After this client's own leads or searches show the pattern → `first_party`
- After MF13 shows cash from the campaign → `proven`
- After a campaign ran properly and produced nothing → move it **down**, and record why.
  A negative result is a result.

## Why it matters commercially
`proven` is what justifies scaling spend. If everything is sitting at `hypothesis` after six
months of delivery, the learning loop is not running — which is a problem with MF13, not with
the opportunities.
