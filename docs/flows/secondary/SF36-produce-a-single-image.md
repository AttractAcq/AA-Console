# SF36 — Produce a single image asset

**Where.** Clients → [client] → Delivery → Content Production Factory → Create
**Owner.** Creative lead. **Reviewed.** 25 October 2026. **Part of** MF07.

## Do it
1. Brief it with **Format** = `single` (SF34).
2. **Approve & build.**
3. The creative build agent produces it. Stages: `concept` → `render` → `done`.
4. It lands in **Images**.
5. Copy (SF40), QA (SF41), then approval (SF42).

## Reading the brand
The build reads the brand profile from **Account → Brand & Design**. An empty brand profile
produces off-brand output that then fails brand QA — fix the profile, not the image.

## Gotcha
A single image is the cheapest asset to produce and the easiest to produce too many of. The
constraint should be the pillars and the awareness journey, not how fast the agent is.
