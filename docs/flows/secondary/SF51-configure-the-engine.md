# SF51 — Set the engine's horizon, mix and approval mode

**Where.** Clients → [client] → Delivery → Organic Content Distribution → Engine
**Owner.** SMM. **Reviewed.** 25 October 2026. **Part of** MF09.

## The settings
| Setting | How to choose |
|---|---|
| **Plan ahead days** | A week or two. Longer horizons plan content against stale intelligence |
| **Format mix** | What the platform and the niche actually reward, not what is cheap to make |
| **Approval mode** | Start at the strictest. Loosen only after weeks of right output |
| **Minimum QA score** | The floor for offering something for approval. Raise it if weak work reaches you |
| **Window day / Window start / Window end** | The client's audience's hours, not yours |
| Max jobs in flight | Leave it unless the runtime is saturated |
| Auto-approve ideas / briefs | Internal artifacts only. Reasonable once pillars are proven |

## What auto-approve does and does not do
Auto-approving ideas and briefs skips the human step on **internal** artifacts. It never
skips the publishing gate. The content still stops at `awaiting_approval` for a person.

## Gotcha
**Do not lower `min_qa_score` to clear a backlog.** It converts a quality problem into
published weak content. If nothing is reaching you for approval, read the QA detail and fix
the briefs (SF41).

## Then
Turn `enabled` on (SF06) and watch the slot board (SF52).
