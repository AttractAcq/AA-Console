# SF20 — Sign off an offer version

**Where.** Clients → [client] → Delivery → Offer Studio → Service Offers
**Owner.** Client manager, with the client's agreement. **Reviewed.** 25 October 2026.
**Part of** MF03, MF04, MF11, MF15.

## The one rule
**Sign-off refuses a quantified claim with no proof behind it.** That refusal is the single
most valuable gate in Offer Studio: it is what stops an unevidenced number reaching a public
page or an ad.

## Do it
1. Read the version in full, as a customer would.
2. Check each claim has what it needs (SF21).
3. Sign it off.

The newest **signed-off** version is what "current" means. A draft v4 nobody approved does
not make a live v3 wrong.

## If sign-off is refused
The refusal names a claim with no `proof_asset_id`. Options, in order of preference:
1. Get the proof (SF23, SF24) and attach it.
2. Soften the claim so it is no longer quantified.
3. Remove the claim.

Do not attach loosely-related proof to clear the gate. The claim evidence view (SF21) will
show it, and so will anyone who checks.

## Downstream
Only now can a campaign bind this version, a page quote it, or a magnet carry it.
