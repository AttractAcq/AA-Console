# SF38 — Produce a carousel, and why it publishes whole

**Where.** Clients → [client] → Delivery → Content Production Factory → Create /
**Carousels**
**Owner.** Creative lead. **Reviewed.** 25 October 2026. **Part of** MF07.

## Do it
1. Brief with **Format** = `carousel` (SF34).
2. Build. Each frame is produced, and the set is the asset.
3. Review the set **in order** — a carousel is a sequence and frame four only works after
   frame three.
4. Copy (SF40), QA (SF41), approval (SF42).

## It publishes whole
A carousel goes out as one post with all its frames, never frame by frame. Half a carousel is
not a smaller carousel; it is a broken one. The publishing path treats the set as a unit for
exactly this reason.

## Gotcha
If a single frame is wrong, fix that frame (SF35) and re-approve the set. Do not publish the
set minus a frame.

## Troubleshooting
| Symptom | Cause |
|---|---|
| Went out as one image | The format on the asset was not `carousel` |
| Frames out of order | The frame plan order; fix on the brief |
