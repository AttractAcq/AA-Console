# SF17 — Read opportunity readiness and clear each blocker

**Where.** Clients → [client] → Delivery → Market Opportunities → Activate
**Owner.** Marketing Director. **Reviewed.** 25 October 2026. **Part of** MF02.

## Do it
Read the readiness line. `opportunity_readiness` names what is missing in one sentence.
Clear them one at a time and re-read.

## What it checks, and where to fix each
| Blocker | Fix |
|---|---|
| No awareness journey | SF16 |
| No proof requirements | SF14 — **Add requirement** |
| Not scored / no factors | SF14 |
| No conversion action | SF14 |
| Confidence too low for what you are about to spend | SF15, or accept it and say so |

## Why it blocks
Each item is something a downstream module needs. An opportunity with no awareness journey
produces briefs with nothing to aim at; one with no proof requirement produces a campaign
that stalls waiting for proof nobody asked for in time.

## Gotcha
Readiness is honest — it does not go green because the work looks done. If you think an item
is satisfied and it still blocks, the record is not where you think it is.
