# SF09 — Set content pillars

**Where.** Clients → [client] → Delivery → Intelligence OS (`?view=strategy`) → Content Pillars
**Owner.** Client manager. **Reviewed.** 25 October 2026. **Part of** MF01, MF03, MF09.

## Why it matters
Pillars are what the engine is allowed to talk about. An engine pointed at wrong pillars
produces a lot of wrong content, efficiently.

## Do it
1. **Propose content pillars** — with **Anything to steer the set (optional)**.
   There is also **Generate a set from the brand strategy**.
2. Read the set and edit it. **Generate only appears when there is no active set** — a set is
   active or it is replaced, not quietly edited in place.

## What a good pillar is
Something the client can credibly talk about for months, that a buyer cares about. For a
service business the durable ones are usually: the work itself (process, craft), proof
(results, customers), the expertise (why them), and the decision (how to choose, what to
avoid).

A pillar that is really a campaign — "spring offer" — will run dry in three weeks.

## Downstream
**Pillar Idea** in ideation generates against a specific pillar (SF33), and campaigns can
record which pillars they serve. Revisit pillars when engine output drifts; the engine is
downstream of them.
